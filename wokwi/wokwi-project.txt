Downloaded from https://wokwi.com/projects/new/esp32

This folder contains a simplified version of the Bluetooth Speaker project
that can be simulated in Wokwi online simulator.

Limitations in Wokwi:
- No Bluetooth simulation 
- No I2S/Audio simulation
- Limited ESP-ADF support

What CAN be tested:
- GPIO operations
- Basic system initialization  
- UART communication
- LED indicators for status
- Application logic flow

To use:
1. Go to https://wokwi.com
2. Create new ESP32 project
3. Copy the diagram.json content
4. Copy the simplified test code
5. Run the simulation
